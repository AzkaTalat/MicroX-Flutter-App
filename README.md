# MicroX Flutter App

A Flutter-based application developed for **MicroX**, featuring the Careers section and Team Portal.

## About the Project

MicroX Flutter App is a mobile application that recreates selected pages of the official MicroX website using Flutter and Dart. It provides a responsive interface for exploring career opportunities and accessing the team workspace.

## Features

- Careers Page
- Frontend Developer Internship Details
- Internship Application Form
- Team Portal Login Screen
- Team Portal Dashboard
- Responsive Mobile Layout
- Dark Theme with Red Accents

## Technologies Used

- Flutter
- Dart
- Material Design
- Android Studio

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/AzkaTalat/MicroX-Flutter-App.git
```

**2. Open the project folder**

```bash
cd MicroX-Flutter-App
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

## Build APK

To generate the release APK:

```bash
flutter build apk --release
```

## Note

This project is a frontend demonstration. Login and application form functionality are demo-based and are not connected to a live backend.
